# Seed photos

The demo barbers' portraits, loaded into `providers.photo` by `scripts/seed.py`
when it creates each barber. They are free stock photos from Unsplash, used
under the [Unsplash License](https://unsplash.com/license) (free to use, no
permission needed). The people in them are not the barbers named in the demo.
Each was cropped to 480×600 on the face by Unsplash's image service.
